# Integração Backend

Projeto de integração entre front-end e back-end, com gerenciamento de produtos via requisições a uma API externa.

## Tecnologias

- HTML5
- CSS3
- JavaScript (Fetch API)

## Funcionalidades

- Listagem de produtos consumidos de uma API
- Cadastro e gerenciamento de produtos
- Comunicação assíncrona com back-end via Fetch

## Como executar

Abra o arquivo `index.html` diretamente no navegador. É necessário que a API esteja em execução para o funcionamento completo.
